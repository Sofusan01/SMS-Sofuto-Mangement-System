# อัปเดต C1CONCLUDE

21 ตุลาคม 2569 — ระบบหลัก SMS SOFUTO MANAGEMENT SYSTEM

- เมนูหลัก 3 งาน: ภาพรวม, เพิ่มข้อมูลรายเดือน, สรุป PDF / Excel
- ภาพรวมเลือกเดือนและสาขาหรือรวมทั้งหมด มีปุ่มเลือกสาขาและตารางรวมยอดสาขา
- กรอกลา/สาย/หมายเหตุหลายคนในตาราง แล้วบันทึกเป็นชุดเดียว ถ้ารายการใดผิดจะไม่บันทึกบางส่วน มีการเตือนเมื่อออกก่อนบันทึก
- รายงานเลือกสาขาเดียวหรือทุกสาขา แยกหน้าสาขาหรือรวมตาราง ดาวน์โหลด PDF ได้โดยตรงจากเบราว์เซอร์ด้วยฟอนต์ไทยที่รวมไว้ และยังพิมพ์/ส่งออก Excel ได้
- ช่องลายเซ็นพนักงาน ผู้จัดทำ ผู้ตรวจสอบ ผู้อนุมัติ พร้อมวันที่ลงนาม เป็นช่องสำหรับลงนามภายหลัง ไม่ใช่ลายเซ็นดิจิทัล
- มีสถานะฉบับร่างเมื่อข้อมูลยังไม่ครบ ป้องกันการเข้าใจยอดที่ยังไม่บันทึกเป็นศูนย์ที่ตรวจแล้ว

ตรวจสอบผ่าน: สูตรและชุดข้อมูล 11 กรณี, API บันทึกชุดบนฐานข้อมูลทดสอบแยก, การกรองสาขา, HTML escaping, การแบ่งหน้า, PDF จริงครบ 5 สาขา (5 หน้า) และแม่แตง (1 หน้า), ตัวอักษรไทย/อังกฤษและภาพ PDF ทุกหน้า

ไฟล์ PDF ตัวอย่างใช้ยอดตั้งต้นกันยายน 2569 และยังไม่มีบันทึกรายเดือน จึงระบุฉบับร่าง ไม่ใช่สรุปที่ยืนยันแล้วสำหรับหักเงินจริง

ข้อจำกัด: เบราว์เซอร์อัตโนมัติติดอยู่ที่หน้าเชื่อมต่อผิดพลาดและนโยบายไม่ให้ตรวจหน้านั้น จึงยังไม่ได้ตรวจการกดปุ่มดาวน์โหลดจากหน้าจอรุ่นล่าสุด แต่ทดสอบฟังก์ชันสร้าง PDF ตัวเดียวกับแอปและเปิดตรวจไฟล์จริงแล้ว และตรวจ HTTP ของแอปกับส่วนประกอบ PDF ตอบ 200 ทั้งหมด
